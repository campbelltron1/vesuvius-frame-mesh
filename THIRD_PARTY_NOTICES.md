# Prior work and data notices

No third-party source code is bundled in this repository. The public metadata
and benchmark evidence derive from Vesuvius Challenge datasets and the work
credited in the README, especially Villa issues #1727 and #1845 and PR #1944.
The original cross-scan experimental harness used during development was
released under MIT by TAUIL Abd Elilah; it is not included in this clean
resolver repository.

The complementary `tifxyz-canvas-map` project by Sebastien Chicoineau
(`@slchicoineau-creator`) and Chris Thomas (`@Baz248`) maps pixels between an
already selected fine/coarse TIFFXYZ pair. Its source code and CC BY-NC
evidence table are not bundled here; its coordinate formula, 207-pair table,
and physical residual measurements remain that project's work. See
`docs/RELATED_CANVAS_MAPPING.md`.
